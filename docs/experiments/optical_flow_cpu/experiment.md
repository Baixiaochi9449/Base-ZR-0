# Optical Flow CPU Verification

- Created: 2026-09-06; owner: repository user / Codex implementation.
- Purpose: data structure audit, real AR checkpoint initialization and 16-sample
  OF-only head overfit. This is a CPU verification, not formal training.
- Code baseline: see `verification_results.json` generated by the command below.
  Uncommitted changes: optional optical flow implementation and tests in this task.
- Base model for initialization: existing Qwen3-VL AR-only checkpoint at
  `outputs/pretrain/tabletop_v3_dq32_ar_gbs128_seed42_mbs16_gas2/step-7284`.
  Compare every saved VLM tensor and the saved Difference Query exactly.
  Action Expert must not be constructed or executed.
- Dataset: LIBERO v3 Stage06 manifest `2849ed69240ad542`; train episodes 0..1692,
  273465 frames, 10 FPS. Audit validates all declared structures; dense reading and
  overfit use 16 eligible frames of episode 0. No validation/test split is inferred.
- Camera: `observation.images.image`; labels are MegaFlow pseudo-labels with
  finite/in-bounds masks (not occlusion labels). Delta=10, tail excluded.
- Scale: GPU count=0; CPU batch=16; gradient accumulation=1; 320 optimizer updates;
  5120 sample presentations. The GPU global batch formula is not applicable to
  this CPU unit experiment; global CPU batch = 1 process x 16 x 1 = 16.
- Overfit input: fixed synthetic `[16,4,32]` query states, seed=42, no images
  or language/action inputs. Target `[16,2,224,224]` -> mask-aware area 56x56.
  Components retain normalized-source-extent units. No crop/pad/augmentation.
  Actual image preprocessing is separately checked with the Stage06 adapter.
- Modules: train only Flow Head (hidden=32, grid=14, heads=8, layers=1);
  synthetic query inputs frozen; no visual encoder, merger/projector, language
  model, Action Expert or Slot participates in overfit. Production defaults are
  hidden=256, layers=2. Query count is not a parameter-count multiplier.
- Optimizer: AdamW, all Head parameters, LR=0.0003 constant (min=peak),
  weight decay=0, betas=(0.9,0.999), epsilon=1e-8; no warmup, LR multipliers,
  clipping, scheduler, scaler, checkpointing or early stopping. Float32.
- Loss: `OF = mean_eligible(robust_EPE_valid + robust_EPE_motion)`;
  `robust_EPE = sqrt(dx^2+dy^2+1e-6)-0.001`, motion threshold=.01,
  minimum cell valid fraction=.5. OF weight=1; AR/FM/Slot are not computed.
- Validation: initial/final EPE, zero-flow baseline, initial/final OF loss;
  no rollout, execution horizon, control loop or action checkpoint output.
- Output: this document and `verification_results.json`; no model checkpoint.
  W&B project/group/run/URL: N/A for this explicitly authorized CPU test.
- Command (run from repository root):

```sh

  /opt/data/private/lq/miniconda3/envs/ZR-0/bin/python scripts/verify_optical_flow_cpu.py \
  --checkpoint outputs/pretrain/tabletop_v3_dq32_ar_gbs128_seed42_mbs16_gas2/step-7284 \
```
